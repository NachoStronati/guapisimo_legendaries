# Compatibilidad

## Requisitos

| Mod | Versión |
|---|---|
| Minecraft | 1.21.1 |
| Fabric Loader | 0.16 o superior |
| Fabric API | Para 1.21.1 |
| Cobblemon | 1.8.4 o superior |
| Cobblemon: Mega Showdown | Para 1.8.4 |
| Chipped | Para 1.21.1 |

Los tres son **obligatorios**: el mod usa objetos y bloques de Mega Showdown y de Chipped.

## Pensado para jugar con

### Legendary Monuments

Guapisimo Legendaries es un **complemento** de Legendary Monuments: solo añade legendarios que ese mod **no** tiene, así que podéis tener los dos instalados sin que se repita ninguno.

### Cobblemon: Mega Showdown

Además de ser obligatorio, Mega Showdown ya trae métodos para **Zygarde** y **Terapagos**, así que este mod no los incluye. Eso sí, en las ruinas de Koraidon puedes encontrar **Células** y **Núcleos de Zygarde**.

## Problemas conocidos

- **YUNG's Better Jungle Temples** cambia el loot de los templos de la jungla. Si lo usas, puede que los Fragmentos de Ídolo no salgan en esos cofres. En la arqueología del desierto y de las ruinas de senderos siguen saliendo.
- **Mods que cambian el loot de los cofres vanilla**: las páginas, las piezas de Magearna y los fragmentos se añaden a las tablas de Minecraft. Si otro mod las sustituye por completo, puede que no salgan.
